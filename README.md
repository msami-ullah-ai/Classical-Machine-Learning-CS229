# Classical Machine Learning — CS229 (Stanford, Autumn 2018)

## 📌 Overview

This repository is a **research-oriented implementation** of the Stanford CS229 (Autumn 2018) curriculum, focused on building machine learning algorithms **from first principles**.

Rather than relying on high-level libraries, this project emphasizes:

* Mathematical rigor
* Algorithmic understanding
* Clean, from-scratch implementations

The goal is to deeply understand *why* machine learning works — not just how to use it.

---

## 🎯 Objectives

* Reproduce core CS229 algorithms from scratch using NumPy
* Derive key equations and optimization procedures mathematically
* Solve and document CS229 problem sets rigorously
* Bridge theory ↔ implementation
* Build strong intuition for classical ML methods

---

## 🧠 Core Philosophy

> “If you can’t derive it, you don’t fully understand it.”

This repository prioritizes:

* Mathematical derivations before coding
* Minimal abstraction (no sklearn for core logic)
* Transparent, readable implementations
* Reproducibility and clarity
